# 경영기획실 소개 페이지

Next.js(App Router)로 만든 경영기획실 소개 1페이지 사이트입니다.
좌우 분할 레이아웃 · 강의모드 토글 · 반응형(모바일 드로어)을 지원합니다.

## 구성
- **HR 파트** / **재무회계 파트** 소개와 담당 업무
- 좌측 사이드바: 목차(스크롤 스파이) + 강의모드 토글
- 디자인: Slack 디자인 시스템(아우버진 + 따뜻한 아이보리 + 멀티컬러 액센트) 참고

## 개발

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 프로덕션 빌드
```

## 배포
GitHub `main` 브랜치에 push하면 Vercel이 자동으로 프로덕션 배포합니다.
